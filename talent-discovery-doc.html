一、产品概述

1.1 产品定位

天赋星鉴 是一款融合东方命理学（八字 / 五行）与西方心理学（MBTI / 霍兰德）的综合天赋分析平台。用户通过填写出生信息和完成多项测评，获得个性化的天赋分析报告，帮助了解自身先天特质与职业发展方向。

1.2 核心价值主张

  • 融合东方智慧 × 现代心理学
  • 四大测评维度，全面解码天赋密码
  • 三步找到你的天赋：填写信息 → 完成测评 → 获取报告

1.3 四大测评模块

模块理论依据说明
性格分析八字命理学通过出生日期排盘，分析五行、十神、大运等先天特质
MBTI 人格Myers-Briggs 类型指标15 道二选一题，确定 16 种人格类型
霍兰德测评John Holland 职业兴趣理论15 道量表题，评估六维职业兴趣
天职测评天职发现理论框架15 道量表题，从天赋/热情/价值三维度发现职业使命

1.4 技术架构

  • 前端：Next.js 15 + React 19 + Tailwind CSS 4（App Router）
  • 后端：Express + TypeScript + Prisma ORM + SQLite
  • 身份认证：JWT（7 天有效期）
  • 服务端口：前端 3000 · 后端 3001

二、用户系统

2.1 用户注册

用户在注册页面填写以下信息创建账号：

字段类型说明
昵称文本输入必填，显示在仪表盘
邮箱Email 输入必填，唯一标识
密码密码输入最少 6 位，bcrypt 加密存储

注册成功后自动返回 JWT 令牌，并跳转至仪表盘。

2.2 用户登录

  • 邮箱 + 密码登录验证
  • 成功后返回 JWT（7 天有效期）及用户信息
  • Token 存储于浏览器 localStorage

2.3 密码重置

  • 忘记密码：输入邮箱 → 生成重置令牌（1 小时有效）→ 返回重置链接
  • 重置密码：携带令牌 → 输入新密码 → 更新成功

注：当前未配置邮件服务，重置链接直接在 API 响应中返回。

三、仪表盘

3.1 功能概览

登录后的主界面，展示测评进度与各模块入口：

  • 进度条 — 显示已完成测评数量（X/4）
  • 模块卡片 — 四大测评模块入口（图标 + 标题 + 描述 + 完成状态）
  • 生成综合报告按钮 — 条件触发：完成性格分析 +（MBTI 或霍兰德）
  • 我的报告 — 查看已生成的报告列表

3.2 模块状态管理

系统自动检测用户在各模块的结果记录，标记为"已完成"（绿色勾）或"未完成"（灰色圈）。状态变化影响报告生成条件。

3.3 导航与用户操作

  • 顶部导航栏显示品牌 Logo 及用户昵称
  • 退出登录按钮
  • 报告快捷入口

四、模块一：性格分析（八字排盘）

模块 ID：bazi  |  路由：/assessments/bazi  |  后台 API：POST /api/bazi/calculate

4.1 模块说明

基于中国传统八字命理学，通过用户的出生年月日时进行排盘，计算四柱、五行、十神、大运等信息，分析先天性格特质。系统使用 lunar-javascript 库完成农历转换与天干地支计算。

4.2 用户输入字段

序号字段输入类型说明
1出生日期（公历）日期选择器必填
2性别下拉选择男 / 女
3时辰（0-23 时）下拉选择默认 8 时（辰时）
4分钟（0-59）数字输入默认 0

4.3 输出结果说明

  • 四柱信息 — 年柱、月柱、日柱、时柱 + 纳音五行
  • 日主分析 — 日柱天干对应的性格特质（甲-癸，共 10 种）
  • 五行分布 — 木 / 火 / 土 / 金 / 水的数量统计与强弱分析
  • 用神 / 忌神 — 五行平衡中需补充 / 制约的元素
  • 十神格局 — 社会关系模式分析（比肩、劫财、食神等 10 种）
  • 大运走势 — 每十年一运的运势周期（8 个周期）
  • 五运六气 — 先天体质分析与中医调养建议（含易发问题、参考用药）

4.4 计算逻辑简述

  • 四柱：公历转农历 → 提取年 / 月 / 日天干地支 → 推算时柱（五鼠遁）
  • 纳音：60 甲子纳音表查询
  • 日主五行：天干对应的五行属性（甲木、乙木、丙火……）
  • 用神 / 忌神：取最弱 / 最强的五行元素
  • 十神：各天干与日主的关系（10 × 10 查表）
  • 大运：阴阳年 + 性别决定顺逆，每运 10 年
  • 五运六气：年干定五运（太过 / 不及），年支定六气（司天 / 在泉），5 × 6 组合分析

五、模块二：MBTI 人格测评

模块 ID：mbti  |  路由：/assessments/mbti  |  题目数：15 题  |  答题方式：二选一（A/B）

5.1 模块说明

基于 Myers-Briggs 类型指标 理论，通过 15 道二选一题目，评估用户在四个维度上的偏好，得出 16 种人格类型之一。

5.2 四个评估维度

维度全称两极
EI外向 (Extraversion) / 内向 (Introversion)E（外向）↔ I（内向）
SN实感 (Sensing) / 直觉 (Intuition)S（实感）↔ N（直觉）
TF理性 (Thinking) / 感性 (Feeling)T（理性）↔ F（感性）
JP判断 (Judging) / 感知 (Perceiving)J（判断）↔ P（感知）

5.3 测评题目

#问题维度选项 A选项 B
1周末你更倾向于？EI约朋友聚会自己待着
2在团队中你通常？EI主动发言更多倾听
3你获取能量的方式？EI和人交往独处思考
4你的社交风格是？EI朋友多且广朋友少但深
5你更关注？SN具体的事实细节整体的概念可能
6你更相信？SN亲身经验直觉预感
7你更喜欢谈论？SN实际事务未来设想
8学习时你喜欢？SN按部就班先看全貌
9做决定时你更依赖？TF逻辑分析内心感受
10你更看重？TF公平公正和谐体谅
11别人倾诉时你会？TF分析问题给予安慰
12你更容易被说服？TF数据和逻辑情感共鸣
13你更喜欢？JP计划安排灵活随意
14你的桌面通常是？JP整洁有序随性摆放
15面对截止日期？JP提前完成最后冲刺

5.4 评分逻辑

  • 每道题选 A 得 2 分，选 B 得 1 分
  • 分别汇总 E/I/S/N/T/F/J/P 各方向的得分
  • 维度倾向值公式：(正向分 − 反向分) / (正向分 + 反向分) × 100
  • 正值为前者（如 E），负值为后者（如 I）
  • 四个维度倾向字母组合为最终类型（如 INTJ）
  • 全部 16 种类型均有对应的描述文本

六、模块三：霍兰德职业测评

模块 ID：holland  |  路由：/assessments/holland  |  题目数：15 题  |  答题方式：1-5 分 Likert 量表

6.1 模块说明

基于 John Holland 的职业兴趣理论（RIASEC 模型），通过 15 道量表题评估用户在六种职业兴趣类型上的倾向，得出三位霍兰德代码及推荐职业方向。

6.2 六维职业兴趣类型

类型名称特质描述推荐职业（示例）
R现实型动手操作、具体任务、工具机械工程师、技术员、建筑师、飞行员
I研究型钻研原理、分析数据、科学发现研究员、医生、程序员、数据分析师
A艺术型想象力、创造力、审美表达设计师、作家、音乐家、演员
S社会型帮助他人、倾听理解、合作教师、咨询师、护士、社工
E企业型领导力、竞争、说服力创业者、销售经理、投资顾问
C常规型规范流程、条理有序、注重细节会计师、审计师、行政助理

3我喜欢具体的、看得见成果的任务R1-5 分
4我喜欢钻研问题背后的原理I1-5 分
5我善于分析数据和发现规律I1-5 分
6我对科学发现和新知识很感兴趣I1-5 分
7我有丰富的想象力和创造力A1-5 分
8我喜欢写作、绘画、音乐或摄影A1-5 分
9我欣赏美的事物，有独特审美A1-5 分
10我喜欢帮助他人解决问题S1-5 分
11我善于倾听和理解他人S1-5 分
12别人的成长会让我有成就感S1-5 分
13我有较强的领导力和说服力E1-5 分

6.4 评分逻辑

  • 分别汇总 R/I/A/S/E/C 六个维度的得分（每题 3 题，单维度满分 15 分）
  • 按得分从高到低排序
  • 取前三位字母作为霍兰德代码（如 RIA）
  • 根据得分最高的类型推荐职业方向（每类型 10 个，上限 6 个）

七、模块四：天职测评

模块 ID：tianzhi  |  路由：/assessments/tianzhi  |  题目数：15 题  |  答题方式：1-5 分 Likert 量表（非常不同意 → 非常同意）

7.1 模块说明

基于"发现你的天职"理论框架，通过 15 道量表题，从 天赋（Talent）、热情（Passion）、价值（Value） 三个核心维度评估用户，帮助找到最适合的职业使命方向。

7.2 三维度框架

  • 天赋（Talent） — 你擅长什么？（5 题，含分析型、创意型、社交型、执行型、实践型 5 个子维度）
  • 热情（Passion） — 你热爱什么？（5 题，含探索发现、创造建设、助人成长、引领改变、精进专研 5 个子维度）
  • 价值（Value） — 你看重什么？（5 题，含成就导向、平衡导向、影响导向、自由导向、安全导向 5 个子维度）

7.3 测评题目

#问题主维度分值
1我擅长时间规划和任务管理天赋（Talent）1-5 分
2我经常有新奇的想法和创意天赋（Talent）1-5 分
3我善于理解他人的感受和需求天赋（Talent）1-5 分
4我喜欢分析数据、发现规律天赋（Talent）1-5 分
5我动手能力强，能把想法变成现实天赋（Talent）1-5 分
6探索未知领域让我兴奋热情（Passion）1-5 分
7创造新事物让我充满动力热情（Passion）1-5 分
8帮助他人成长让我感到满足热情（Passion）1-5 分
9带领团队实现目标有成就感热情（Passion）1-5 分
10我愿意花大量时间钻研一个领域热情（Passion）1-5 分
11获得成就和认可对我很重要价值（Value）1-5 分
12工作与生活的平衡很重要价值（Value）1-5 分
13我希望工作对社会有积极影响价值（Value）1-5 分
14拥有自主权和自由对我很重要价值（Value）1-5 分
15稳定和安全感是我看重的价值（Value）1-5 分

7.4 评分逻辑

  • 分别汇总天赋、热情、价值三个主维度得分（各 5 题，满分 25 分）
  • 各主维度下含 5 个子维度，每子维度 1 题，用于精细化分析
  • 综合各维度得分生成天职建议文本

八、测评报告系统

8.1 报告生成条件

  • 必要条件：完成性格分析 +（MBTI 或霍兰德测评中的至少一项）
  • 建议条件：完成全部四项测评，可获得最完整的报告

8.2 报告结构

生成的综合报告包含以下 5 个章节：

（1）先天分析

  • 四柱信息 — 年 / 月 / 日 / 时柱及纳音五行
  • 日主分析 — 天干对应的先天性格特质
  • 五行分析 — 五行分布强弱及对应的职业特质
  • 十神格局 — 社会关系模式分析
  • 大运走势 — 十年运势周期描述
  • 五运六气 — 先天体质与中医调养建议

（2）MBTI 人格类型

  • 类型标识（如 INTJ）
  • 四维度倾向百分比
  • 类型详细描述

（3）霍兰德职业兴趣

  • 三位霍兰德代码
  • 六维度得分排序
  • 推荐职业方向（上限 6 个）

（4）天职分析

  • 综合天职推荐文本

（5）综合天赋分析

  • 命理与人格的呼应 — 八字日主 × MBTI 交叉分析（阳干 + E、阴干 + I 等组合）
  • 五行与职业兴趣的关联 — 最强五行 → 霍兰德类型映射（木→A、火→S/E 等）
  • 天赋发展建议 — 根据日主（10 种）+ MBTI 类型（16 种）给出个性化方向

8.3 数据可视化

  • 五行分布图 — 根据五行数量显示彩色圆点（木/火/土/金/水）
  • MBTI 维度条 — 四维度倾向百分比条形图
  • 霍兰德柱状图 — 六维得分横向柱状图
  • 大运时间线 — 可横向滚动的运势卡片

8.4 报告附加功能

  • 分享功能 — 生成分享链接，他人无需登录即可查看
  • 删除管理 — 用户可删除历史报告
  • 打印导出 — 浏览器打印输出为 PDF

8.5 API 端点

端点方法说明
/api/reports/generatePOST生成报告（需认证）
/api/reportsGET获取报告列表（需认证）
/api/reports/:idGET获取单份报告（需认证）
/api/reports/:idDELETE删除报告（需认证）
/api/reports/:id/sharePOST生成分享链接（需认证）
/api/shared/:tokenGET公开访问分享的报告（无需认证）
